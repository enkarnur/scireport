# 文研智库（SciReport）

文研智库是一款面向 Windows 与 macOS 本地使用场景设计的 AI 文献管理软件。它希望把“PDF 文献库、学术批注、结构化阅读、知识库问答、系统综述报告”放在同一个工作台里，让研究者不再只是在文件夹里堆论文，而是拥有一个可以持续积累、主动回答、自动组织证据的个人 AI 研究助理。

> 核心理念：文献不只是文件，而是可以被检索、追问、比较、汇报和复用的知识资产。

## 为什么需要文研智库

传统文献管理工具擅长保存 PDF、维护引用格式和整理标签，但当论文数量变多后，真正耗时的工作往往是：快速判断一篇文章讲了什么，在几十篇论文里找到某个问题的答案，定位原文证据，整理批注，最后把阅读结果组织成一份可以交付的综述或汇报。

文研智库把这些步骤串成一个完整流程：用户把 PDF 放入文献库后，系统通过用户自己配置的 AI API 对论文进行结构化分析，提炼摘要、背景、方法、结果和讨论；当用户提出问题时，系统会在文献库中检索相关证据，再调用 AI 基于证据生成回答；当需要汇报时，系统可以按模板生成系统综述、研究对比或证据摘要，并保留可回溯的页码、章节和原文片段。

## 当前核心功能

### 1. 本地 PDF 导入与页级文本提取

文研智库在浏览器侧读取 PDF，并提取页级文本信息。原始 PDF 不会被上传到后端，后端只保存解析后的文本、页码、元数据与结构化结果。这种设计适合个人电脑上的本地文献管理，也更容易控制隐私边界。

### 2. AI 结构化文献解析

导入论文时，应用会调用用户配置的 OpenAI 兼容 AI API，对论文进行结构化研析，输出摘要、研究背景、方法设计、实验结果和讨论局限。对于英文论文，中文报告模式会以中文进行归纳和表达，而不是简单粘贴英文原文。

### 3. 文献库问答

用户可以直接向整个文献库提问，例如“这些论文主要讨论了哪些问题”“某个方法相比基线提升在哪里”“哪些论文提到实时视频问诊的安全风险”。系统会先检索相关论文与片段，再调用 AI 基于命中的证据作答，并展示引用线索，避免无依据生成。

### 4. 批注记录与快速定位

文研智库支持为任意论文添加批注，记录页码、章节、原文片段和个人理解。批注可以被检索，也可以参与问答和报告生成，让你的阅读痕迹真正沉淀为后续研究资产。

### 5. 系统化文献报告

应用支持模板化报告生成，包括系统综述、研究对比和证据摘要。报告会围绕研究问题组织内容，并尽量保留引用证据和定位信息。生成结果可以导出为 Word，便于继续编辑、投稿准备、组会汇报或项目归档。

### 6. 用户自定义 AI API

应用不内置任何 AI API Key，也不会在代码仓库中硬编码密钥。用户需要在设置页中输入自己的 AI API Base URL、模型名称和 API Key。文献解析、问答和报告生成都会使用用户配置的 AI API 完成。

## 产品工作流

第一步，打开文研智库并进入设置页，填写自己的 OpenAI 兼容 AI API 信息。第二步，在文献库中导入 PDF，等待系统完成结构化解析。第三步，在论文详情页查看摘要、背景、方法、结果和讨论，并按页定位原文。第四步，在阅读过程中添加批注。第五步，在问答页向文献库提问，快速定位答案来自哪些论文。第六步，在报告页选择论文和模板，生成系统化文献报告并导出 Word。

## 适合谁使用

文研智库适合研究生、医生科研人员、工程研发、产品研究、行业分析师，以及任何需要长期阅读和复用大量 PDF 文献的人。它尤其适合需要频繁做文献汇报、课题综述、研究选题比较、技术路线调研和证据整理的场景。

## 安全与隐私说明

文研智库不会在代码中硬编码 GitHub Token、AI API Key 或其他私密凭据。AI API Key 由用户在设置页输入，并通过应用后端保存到本应用的数据存储中；接口返回时只展示脱敏后的 Key 状态，不返回明文。PDF 原文件默认只在浏览器本地读取，应用保存的是提取后的文本与分析结果。

如果你准备处理高度敏感或未公开资料，建议使用你自己信任的模型服务、私有化部署网关或内网 OpenAI 兼容服务。

## 技术特性

文研智库采用本地优先的产品思路，前端负责 PDF 文本提取与交互工作台，后端负责文献数据管理、批注、检索、AI 调用和报告生成。当前 AI 接口采用 OpenAI Chat Completions 兼容协议，因此可以接入 OpenAI、兼容代理、本地模型网关或企业内部模型服务。

## 在建与规划功能

文研智库的目标不是只做一个“能问 PDF 的工具”，而是成为研究者的个人文献智能中枢。后续规划包括：相似文献查找，根据当前论文自动推荐研究主题相近、方法相似或结论互补的文献；研究脉络图谱，自动梳理论文之间的任务、方法、数据集和结论关系；批量文献对比，自动生成多篇论文在研究问题、实验设置、指标、局限上的对照表；自动选题助手，根据文献库识别研究空白、潜在创新点和可行的后续实验；引用网络与影响力分析，帮助用户发现关键论文、源头工作和最新延伸；多模型适配，支持更多 OpenAI 兼容模型、本地 LLM 和机构私有模型；桌面端文件夹监听，未来可自动监测指定文件夹中新加入的 PDF 并进入解析队列。

## 当前状态

这是一个正在快速迭代的 AI 文献管理项目。当前版本已经覆盖从 PDF 导入、AI 解析、批注、文献库问答到报告生成的主流程。后续会继续增强检索质量、报告深度、相似文献推荐、知识图谱和桌面端体验。
